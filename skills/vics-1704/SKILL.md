# VICS 1704 결성계획신청 입력

실제 결성계획신청 입력 과정을 화면에서 확인한 기록이다. VICS는 웹이 아니라 PC 설치형 프로그램(XPlatform)이다.

## 법률 자문 아님

이 스킬은 공개된 법령·매뉴얼에 근거한 일반 정보와 서류 작성 보조만 제공한다. 사용자 개별 사안에 대해 "적법하다/위법이다" 같은 법적 결론을 단정하지 말고, 요건과 근거를 제시한 뒤 판단이 필요한 부분은 변호사나 소관 기관 확인을 권한다. 답변에 법적 판단이 섞이면 끝에 한 줄을 붙인다: "일반 정보이며 법률 자문이 아닙니다(not professional legal advice)."

## 순서

1. VICS 실행 → GP 공동인증서로 로그인(사용자 본인)
2. 왼쪽 메뉴 [VC]등록/변경/출자신청 > 1704 개인투자조합신청을 연다
3. 오른쪽 위 [결성계획신청] → '개인투자조합신청 상세' 창에 아래 값을 입력 → 조합명 [중복확인]
4. 첨부파일 [파일추가] → 파일 열기 창의 파일 이름 칸에 전체 경로를 넣고 Enter (한 번에 한 건씩 5번)
5. 첨부마다 '파일유형'을 지정 (아래 표)
6. 위쪽 도구모음 [저장] → 목록에 '미제출 / 신청' 행이 생겼는지 확인
7. 그 행의 [공동인증]을 누르면 제출된다. GP 개인용 공동인증서로 본인이 직접 누른다

## 상세 창 입력값

| 필드 | 입력 |
|---|---|
| 모펀드출자여부 | 체크 안 함 (모태펀드 출자사업에 선정된 조합만 체크) |
| GP자격대구분 | 개인 |
| GP자격구분 | 개인투자조합 운용 5년 / 전문개인투자자 / 투자심사 2년(또는 관리 3년) / 교육과정 중 해당 항목 |
| 조합명 | 서류와 같은 이름 → [중복확인] → '신청 가능한 조합명입니다.' |
| 조합구분 | 개인투자조합 (기본값) |
| 신청구분 | 결성계획신청 (자동) |
| 소재지 | 우편번호·도로명은 GP 등록주소가 기본으로 들어온다. 상세주소를 서류의 주된 사무소와 똑같이 고친다 |
| 담당지방청 | 소재지에 따라 자동 |
| 조합결성금액 | 출자총액 |
| 신청사유 | 신규결성 |
| 모펀드결성금액, 출자사업선정명 | 비움 |
| 신청서 정보, 업무집행조합원 정보 | 비움 (등록·변경·청산 신청용) |

## 첨부 파일유형

| 붙임 | 파일 | 파일유형 |
|---|---|---|
| 1 | 결성계획서 | 등록서류 |
| 2 | 전문성 요건 충족 확인서 (GP 서명본) | 등록서류 |
| 3 | GP 자격 증빙 (기존 조합 등록원부 등) | 등록서류 |
| 4 | GP 개인(신용)정보 동의서 (서명·자필본) | 개인(신용)정보 수집·이용 동의서 |
| 5 | 규약(안) — 날짜 공란·미날인 | 등록서류 |

## 주의

- 파일유형 '기타'는 쓰지 않는다. '등록서류' 유형이 하나도 없으면 저장할 때 '[첨부파일 등록신청서류]는 필수입력항목' 오류가 난다.
- 파일유형 목록은 마우스로 항목을 누르면 자주 빗나간다. 목록을 연 뒤 ↑/↓ 키로 고르고 Enter를 누르는 편이 정확하다.
- 미제출 상태에서는 [수정]·[삭제]가 되지만 제출 후에는 보완요청·반려 건만 고칠 수 있다.
- 보완요청을 받으면 기존 첨부를 삭제하고 고친 파일을 다시 올린다. 보완 기간은 처리기간에 넣지 않는다.
- 승인되면 결성총회 후 14일 이내에 같은 1704 화면의 [등록신청]으로 등록한다 (결성계획 승인 행을 선택해야 버튼이 켜진다).

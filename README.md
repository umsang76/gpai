# GPai — 개인투자조합 결성

> ※ 이 플러그인의 답변과 작성 서류는 일반 정보 제공과 실무 보조를 위한 것이며 법률 자문이 아닙니다(This is not professional legal advice). 개별 사안의 법적 판단은 변호사 등 전문가와 소관 기관(중소벤처기업부, 한국엔젤투자협회)에 확인하세요.

한국 개인투자조합(벤처투자법)의 업무집행조합원(GP)이 조합을 결성할 때 Claude가 실무 순서대로 도와주도록 만든 플러그인입니다. 실제 결성계획신청과 VICS 입력 과정을 기록한 기준을 담았습니다.

## 할 수 있는 일

- **결성 전 요건 점검**: 출자총액, 1좌 금액, 조합원 수, 존속기간, GP 자격 근거, 조합명 규칙 등을 확인하고 미충족 항목만 알려 줍니다.
- **결성계획신청 서류 구성 안내**: 붙임1~5(결성계획서, 전문성 요건 확인서, GP 자격 증빙, 개인신용정보 동의서, 규약안)의 작성·서명·날인 기준과 서류 간 일치 규칙.
- **VICS 1704 입력 절차**: 상세 창 필드별 입력값, 첨부 파일유형 지정('기타' 사용 금지), 저장·제출 순서.
- **날인본 검수**: 서명·날인 스캔본을 서류별로 나누고 제출 전 확인할 항목.
- **등록 단계**: 결성총회 의사록·서면결의서, 조합원명부, 출자증표, 조합인감등록부, 등록신청서를 표준 서식대로 작성(Word), 고유번호증·잔액증명 등 발급 서류 안내, VICS 등록신청과 제출 전 검수.

## 사용 예

- "개인투자조합 결성하려는데 요건부터 점검해줘"
- "결성계획신청에 낼 서류 목록과 서명할 곳 알려줘"
- "VICS 1704에서 파일유형은 뭘로 골라?"
- "이 스캔본을 서류별로 나누고 검수해줘"
- "결성총회 서면결의서랑 출자증표, 조합원명부 만들어줘"
